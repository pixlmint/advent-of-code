# Advent of Code Framework

A C# framework for solving Advent of Code problems.

## Features

- CLI tool for local development
- Web platform for visualization and telemetry collection

## Getting Started

1. Create a new solution: `aoc new 2025 1`
2. Run the solution: `aoc run 2025 1 1 --input ./Solutions/Year2025/Day01/input.txt`
3. Run tests: `aoc test 2025 1`
